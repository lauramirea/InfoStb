# InfoStb
Public Transit Pathfinding & Management System | C++

Developed a comprehensive C++ console application to model, analyze, and manage a city's public transportation network using Graph Theory concepts.

Implemented a customized backtracking algorithm to calculate all valid routes and dynamically identify the optimal (shortest/cheapest) path between any two transit stations.

Engineered advanced graph analysis features to detect route cycles, identify isolated stations, determine terminal nodes, and calculate connected components.

Integrated a secure administrator module with file-based authentication, allowing staff to dynamically add stations and manage network data via fstream.

Designed an interactive command-line interface (CLI) providing seamless, menu-driven navigation for both regular commuters and system administrators.
